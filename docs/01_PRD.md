# 01 · 产品需求说明（PRD）

## 1. 产品定位

「练」是一个移动端优先的训练计划 PWA：把「想练成什么样」翻译成周框架和当天可执行的训练清单。用户当天点几个部位，就排几个动作；训练时不计时、不掐点，只记录重量、次数和感受。

- 产品名：练 · 周框架与今日清单
- 形态：React SPA + PWA（可安装到主屏、支持离线打开已缓存页面）
- 数据策略：本机 localStorage 为主，云端只做整份备份；大模型 Key 只存本机
- 商业形态：账号密码 / 支付宝登录 + Pro 订阅（当前仅展示状态与购买入口）

## 2. 目标用户

- 有一定训练基础、不想被固定课表绑住的人
- 想练但不知道怎么安排周计划、每次练什么的人
- 在意隐私，希望训练数据默认留在本机的人
- 有伤病或器械限制，需要动作替代与风险提示的人

## 3. 信息架构

| 一级页面 | 路由 | 说明 |
|---|---|---|
| 运动 | `#/train` | 周框架、今日清单、开始训练 |
| 动作 | `#/moves` | 动作库、按肌群筛选、收藏 |
| 记录 | `#/log` | 运动记录、逐组记录、体重腰围打卡、日历 |
| 吃 | `#/diet` | 三餐/加餐记录、营养库、热量参考 |
| 设置 | `#/settings` | 档案、模型、账号、数据、离线、安全边界 |

流程页：`#/welcome`、`#/setup`、`#/plan`、`#/pick`、`#/session`。
设置子页：`#/settings/profile`、`/model`、`/account`、`/data`、`/offline`、`/safety`。

## 4. 功能清单

### 4.1 训练

- 首次引导填写档案：性别、年龄、身高、体重、体脂、训练年限、伤病、器械、每周可练天数、单次时长、目标愿望
- 调用大模型把愿望翻译成：目标解释、优先发展部位、周框架、训练规则、衡量指标
- 周框架包含：周期（默认 4 周）、每周练几天、每天 focus、动作槽位
- 今日清单：按当天选择的部位生成动作，支持时长预算、载重调整
- 直接开练：不生成周框架，按当前部位即时排动作
- 训练中：逐组记录重量/次数/RPE/是否力竭，支持换动作、跳过、动作注意事项
- 训练结束：写入逐组记录与运动记录

### 4.2 动作库

- 内置动作数据：名称、目标肌群、动作模式、器械、组数/次数、休息秒数、起始重量参考
- 按胸/背/肩/手臂/腿/臀/核心/全身/有氧分类
- 收藏常用动作
- 动作要点、常见错误、伤病风险提示（膝/腰/肩/踝）

### 4.3 记录

- 逐组训练记录（动作、组序、重量、次数、目标次数、RPE、力竭、时间）
- 其他运动记录：类型（有氧/球类/举铁/走路/其他）、时长、感受、部位、备注
- 体重/腰围打卡
- 日历视图查看当天记录

### 4.4 饮食

- 按早餐/午餐/晚餐/加餐记录食物
- 记录热量、蛋白质、碳水、脂肪、糖、钠
- 常见食物营养库检索
- 按档案推算 TDEE、热量参考区间、蛋白质目标
- 体重变化节奏提示（周平均）

### 4.5 设置

- 我的档案：身体数据、训练天数、目标；可跳过身体数据自由练
- 链接大模型：baseURL / apiKey / model，Key 只存本机，可测试连通性
- 账号：账号密码注册/登录、注册前勾选隐私政策与服务条款、修改密码、支付宝登录、退出本机、注销云端账号、Pro 购买
- 隐私政策与服务条款：应用内说明页，注册时必须勾选同意
- 管理后台：仅 `ADMIN` 可见，支持账号搜索、停用/启用、手填天数开通 VIP、查看操作日志；订单管理支持按状态筛选、关闭待支付订单、对已支付订单在线退款（退款后扣回该单 VIP 天数）
- 操作留痕：登录、登录失败、退出、注册、修改密码和管理操作都会写入操作日志；普通用户只能看自己的记录
- 登录可选：不登录仍可使用本机全部功能，登录只用于云端备份与多设备
- 数据与备份：导出 JSON、导入 JSON、云端整份上传/拉回/删除、清空本机
- 离线与安装：安装到主屏、断网可用范围说明
- 安全边界：产品不做什么

## 5. 关键流程

1. 首次进入 `#/welcome` → `#/setup` 填写档案
2. 生成周框架 → `#/plan` 查看 → 回到 `#/train`
3. 当天选部位 `#/pick` → 生成今日清单 → `#/session` 训练记录
4. 训练结束写入记录 → `#/log` 查看
5. 饮食在 `#/diet` 单独记录
6. 需要换设备时：账号密码或支付宝登录 → 设置/数据与备份 → 传到云端 → 新设备拉回

## 6. 安全边界（产品硬约束）

- 不做医疗诊断，不替代医生或注册营养师
- 不安排极限重量、不鼓励带伤硬练
- 不建议低于女性 1600 kcal/天、男性 2000 kcal/天
- 不设计超过 24 小时的断食
- 不推荐补剂具体剂量、不涉及药物或运动营养处方
- 出现疼痛、麻木、关节刺痛时优先停止并建议就医

## 7. 免费与 Pro

当前实现：账号页只展示 `free / pro` 状态、到期时间和购买入口；前后端均未按 `plan` 限制任何功能。

待定义（建议）：Pro 可承载云端自动同步、历史趋势分析、更多模型额度等；免费版保留本机记录与基础计划生成。

## 8. 非目标

- 不做训练计时/倒计时（产品明确「不计时」）
- 不做社交、排行榜、教练入驻
- 不做医疗诊断、康复处方
- 不做食物拍照识别（当前为手动记录 + 营养库检索）

## 9. 已知缺口

- 无统计/趋势页、无提醒通知、Pro 无实际权益
- 云端同步为手动整份覆盖，无冲突处理
- 支付宝登录与支付需要真实应用凭据，本地默认未配置
